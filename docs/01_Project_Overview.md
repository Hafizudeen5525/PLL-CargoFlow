# CargoFlow: Project Overview

## What is CargoFlow?
CargoFlow is a **Commodity Trading & Risk Management (CTRM)** lite dashboard designed for LNG and Oil logistics. It allows traders and operators to manage cargo lifecycles from deal capture to physical delivery and financial settlement.

## Core Value Proposition
1.  **Centralized Data:** Replaces disparate Excel sheets with a unified React dashboard.
2.  **Automated Valuation:** Automatically calculates P&L based on complex pricing formulas (e.g., `JKM + 0.5`, `13% Brent`) against live market data or forward curves.
3.  **AI Automation:** Reduces manual data entry by using Google Gemini to parse PDF/Word "Key Term Sheets" (KTS) and auto-populate deal forms.
4.  **Risk Visualization:** Provides real-time visibility into exposure (Floating vs. Fixed prices), geographical distribution, and shipping schedules.

## Target Users
*   **Traders:** To monitor P&L and unmatched positions.
*   **Operators:** To track loading/delivery windows and shipping schedules.
*   **Risk Managers:** To view exposure against forward curves and ensure books are balanced.
